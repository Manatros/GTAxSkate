GTAxSkate v0.7.0 Story candidate (SK8V 1.1.10)
Gameplay acceptance pending; v0.6.0 remains stable.

Use the exact ID and binary hashes from manifest.json. No game assets are in
this binary-only package. Existing converted SK8V/GTAxSkate data are required.
The separate setup ZIP is for a full installation. No FiveM/Coop parity is claimed.

INSTALL
1. Close GTA V, OpenIV and CodeWalker.
2. Run Install Test.cmd and supply your GTA V Legacy 1.0.3889.0 folder.
   Keep the printed backup path. Both binaries are installed together;
   existing INI, boards and bindings stay intact.
3. Restart GTA in Story Mode with BattlEye off. Keep the composition helper
   disabled; use the existing separate board-part models.

TEST
- Enter through the weapon wheel or SK8V menu. E/Y mounts and dismounts;
  hold it to leave skate mode. F is not an extra mode switch.
- Ride quickly through the city and metro. Revisit the last fall-through and
  floating-collision spots. Compare loading/hitches with the previous build.
- Ride bowls, flagged stairs, handrails and train tracks. Unflagged stairs are
  experimental and off by default.
- Drop a picnic table, flat ramp, half pipe and rail. Ride/grind each. Add and
  remove several; check FPS, seams, duplicate/floating rails and unload delay.
  Compare with the collision overlay off using the same graphics/mod settings.
- Check shop purchases, wheel/truck animation and glow colour; camera V cycle,
  settings persistence, save/reload, weapons and radio.
- Note whether metro texture/collision trouble also happens in GTA mode.
  Stencil causality remains unconfirmed.

ROLLBACK
Run restore-test-build.ps1 -Backup "THE PRINTED BACKUP FOLDER" with GTA and
model tools closed. Settings remain preserved. Do not delete recovery backups.

Report the candidate ID, failing place/action and minimal redacted logs.
Automated tests do not establish stable gameplay FPS or full collision accuracy.
Release requires explicit approval of the exact pair and cannot occur before
24 October 2026. See TEST-RUN.md for the full regression checklist.
