OPTIONAL COMPOSED SHOP BOARD:
Requires existing working SK8V/GTAxSkate data, GTA V Legacy 1.0.3889.0,
Python >=3.10 and the existing pinned RAGE tool. The stable installer does not
enable this helper. Read BOARD-COMPOSITION.md in the source repository.
Keep BoardShop=1 and CarryBoard=0 for comparison; SK8V owns animation/transitions.
1. With GTA closed, configure the separately backed-up helper:
   powershell -NoProfile -ExecutionPolicy Bypass -File composer\setup-board-composer.ps1 -Assets "YOUR ASSETS FOLDER" -Python "YOUR python.exe" -Rage "YOUR rage.exe"
2. Install the binary pair below, then fully restart GTA.
3. Ride and steer. The log should show:
   board parts: riding skatev_c_... (single drawable)
4. Change wheels/deck, paint truck baseplate and hanger separately, select grip.
   Check preview, purchase, riding and return to the saved setup. Preparation
   takes seconds outside the game tick; the existing model stays until ready.
5. Get on/off, put the board away and compare with official SK8V 1.1.10.
6. Follow up on stopping: after riding fast, stand still on the board for
   10 seconds. Roll slowly forward/backward, steer and stop again.
A recording is optional; report the exact failing action and preserve logs.
Helper rollback uses restore-board-composer.ps1 from its printed backup with
-Backup "HELPER BACKUP FOLDER". Binary rollback is separate (see below).

This snapshot requires existing working converted data and installs no assets.
It is not a FiveM/Coop skating port. LS Skate remains unavailable until a verified adapter exists.

INSTALL (GTA, OpenIV, CodeWalker closed):

  Or run:

disabled reversibly to match the normal SK8V installer. INI files, boards,
game saves and archives are left unchanged. Backup/rollback path is printed.
Your current settings are kept: this test does not automatically select RP.

SAVE-RELOAD / CAMERA REGRESSION (priority):
1. Fresh Story start: ride with normal trick HUD and rolling/push/landing sounds.
2. Load an existing save twice, then one in a different location; include a load
   while skating. Do not overwrite saves.
3. After EVERY load: HUD should return without changing presets; sounds should
   follow this ride, and F10/get on/off/boards/collision should continue working.
4. Switch R cinematic/normal and V views near walls, ramps and low ceilings.
   HUD should hide in cinematic and return afterward. Check camera stays outside
   geometry; collision ray tests cannot guarantee every streamed object.
5. F10 > Presets > Developer enables input/debug overlays, verbose logs, keys
   and trick HUD immediately. Developer > Disable diagnostics turns the extra
   overlays/logs off. Driving physics and server rules are unchanged.
   F10 > Developer also shows source basis, host build, test receipt and LS status.
   Receipt is metadata only; LS Skate is not integrated, not auto-detected.
6. Keep logs immediately if anything fails. Note build id, reload number, which
   camera/profile, and timestamp. Logs should show one runtime preload across
   script restarts, suspension/reactivation and a viewport after each restart.
Data/cache paths and creation-only runtime options require a full GTA restart.
The runtime job queue is asynchronous; gameplay recovery still needs this test.
